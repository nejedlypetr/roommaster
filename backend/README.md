# Room Master Backend

This is the backend application for the Room Master project.

## Generating and Accessing Swagger Documentation

This project uses Springdoc-OpenAPI to automatically generate Swagger documentation for the API.

To access the Swagger UI and view the API documentation:

1. Start the application.
2. Open a web browser and navigate to: [`http://localhost:8080/swagger-ui.html`](http://localhost:8080/swagger-ui.html)

This will open the Swagger UI, where you can explore and test the API endpoints.

To access the OpenAPI specification in JSON format, navigate to:
[`http://localhost:8080/v3/api-docs`](http://localhost:8080/v3/api-docs)
